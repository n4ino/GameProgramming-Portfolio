## Featured Project

A 2D Metroidvania game developed as a group project during my game programming studies.

### Metroidvania Group Project "BAMBO"

My responsibilities included:

- Respawn System
- Checkpoint / Rest System
- Forest Echo recovery System
- Shop System
- Cutscene System

Key features I implemented:

#### Respawn System
- Handles player death and respawn.
- Returns player to the last activated checkpoint.

#### Checkpoint / Rest System
- Allows players to activate  checkpoints.
- Saves the respawn location.
- Recovers player health to max.
- Resets and respawns the enemies.

#### Shop System
- Opens shop UI through shopkeeper.
- Allows players to spend collected berries on health upgrades.
- Updates player maximum health after purchase.
- Purchased items are removed from the shopping list.
- Player movement is disabled while the shop is open.

#### Cutscene System
- Controls player movement during events.
- Plays dialogue and scipted sequences.
